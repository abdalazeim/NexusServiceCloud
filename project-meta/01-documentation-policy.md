## حالات المعلومات

- موجود بالمصدر: نص أو فكرة يمكن إرجاعها إلى S1–S5.
- تصميم مقترح: قرار جديد يفصل طريقة العمل، ينتظر الاعتماد.
- مؤجل: قدرة خارج المرحلة الحالية مع بيان سببها واعتمادياتها.
- غير محسوم: سؤال يحتاج قرارًا مسجلًا في Q-01 إلى Q-10.
- متحقق وثائقيًا: فحص ملف أو رابط أو معرف ضمن نطاق محدد.
- متحقق تشغيليًا: لا يستخدم دون تنفيذ واختبار وأثر موثق؛ لا توجد هذه الحالة لأي وظيفة في التسليم الحالي.

وجود descriptor أو README لا يعني Implemented. لا تختلق مقابلات أصحاب مصلحة أو موافقات أو فحوصًا لم تحدث. لا تستخدم رابطًا لملف مستقبلي كأنه موجود؛ ضع اسمه كنص وصرح بحالته.
