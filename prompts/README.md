# دليل مراجعة الحزمة — توثيق فقط

هذه تعليمات مراجعة للإنسان أو مساعد لاحق، وليست إذنًا بتنفيذ النظام. لا تستورد تعليمات التنفيذ المرحلي من NexusAsset ضمن هذا التكليف.

## الجولة الأولى: تحليل الأعمال

اقرأ النطاق وحالات الاستخدام والمتطلبات. راجع مع مالك الخدمة الفرق بين الحادث وطلب الخدمة، والمكاتب السرية، ومقامات التقارير. سجل القرار في Q المناسب دون افتراض موافقة. المخرج: تعديل Markdown ومعايير قبول محددة.

## الجولة الثانية: قواعد المجال

راجع انتقالات الطلب والمشكلة والتغيير والموافقة والاستلام الجزئي والعهدة. اختبر أمثلة SLA يدويًا: نهاية الدوام والعطلة والتعليق وإعادة الفتح. لا تنشئ كود محرك توقيت. المخرج: قواعد متسقة وتحديث تتبع FR إلى AC.

## الجولة الثالثة: تصميم وأمن

تتبع عملية من الشاشة إلى API إلى حالة الاستخدام والمعاملة والحدث والتدقيق. افحص صلاحيات كل رابط وقيود المؤسسة والمكتب والملفات. سجل حالات الفشل والبدائل. المخرج: تعديل التصميم أو ADR مقترح، لا ملفات تطبيق.

## الجولة الرابعة: جاهزية التوثيق

افحص الروابط والمعرفات والمصطلحات والوعود التجارية والمقترحات غير المعتمدة. حدد النواقص الباقية صراحة، ولا تساو بين اكتمال وثيقة وجاهزية إطلاق. إذا طلب تنفيذ لاحقًا، يبدأ بتكليف جديد وحدود مرحلة معتمدة.
