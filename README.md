# NexusServiceCloud — التحليل والتصميم المؤسسي

الإصدار الوثائقي: 1.0 — التاريخ: 2026-11-09 — الحالة: تصميم مقترح للمراجعة.

هذه حزمة تحليل وتصميم لمنصة إدارة خدمات ودعم فني، وليست تطبيقًا منفذًا. جميع السلوكيات والواجهات والنماذج أدناه مواصفات مستهدفة. لا تحتوي الحزمة على شيفرة تطبيق، إعدادات تشغيل، ترحيلات قاعدة بيانات أو اختبارات تنفيذية.

## الفكرة

توحيد استقبال الحوادث وطلبات الخدمة، إدارتها وفق اتفاقيات مستوى الخدمة، وربطها بالمشكلات والتغييرات والإصدارات والمعرفة والأصول والمشتريات والعقود. تدعم الرؤية أقسامًا متعددة داخل المؤسسة، مع عزل مؤسسات مستقلة في النشر السحابي.

## العلاقة بالمراجع

وثائق NexusServiceCloud الأصلية هي مصدر نطاق العمل. استُخدم NexusAsset CloudMonorepo مرجعًا لتنظيم الوثائق وفصل المجال والتطبيق والبنية التحتية والحوكمة. لا يعني ذلك نسخ مجال اكتشاف الأصول، أو اعتماد Lansweeper، أو نقل إصدارات الحزم وخطط التسعير إلى هذا المشروع.

ملفا Architecture.txt وEnterprise Repository Structure.txt الموجودان في الجذر يصفان NexusAsset؛ يبقيان مدخلين مرجعيين دون تعديل. تعريف NexusServiceCloud الحالي هو هذه الحزمة، مع الرجوع إلى [سجل المصادر](docs/14-appendices/01-sources-glossary.md) عند التعارض.

## حدود التسليم

- ملفات Markdown فقط؛ مخططات Mermaid داخل الوثائق للتفسير، وليست برامج.
- المقترحات غير معتمدة تجاريًا أو أمنيًا أو تشغيليًا؛ الاعتماد يسجل بقرار منفصل.
- لا يوجد ادعاء باكتمال API أو تطبيق ITIL أو جاهزية إنتاج أو نجاح اختبارات تشغيل.
- هيكل platform الوارد في التصميم وصف مستقبلي، لا مستودع تطبيق تم إنشاؤه.
- تفاصيل الإصدارات والأسعار وتكاليف الذكاء الاصطناعي والتجربة المجانية تحتاج قرار مالك المنتج.

للمراجعة ابدأ بحسم النطاق والمصطلحات والصلاحيات، ثم قواعد SLA ودورات الحياة، ثم نماذج البيانات والعقود. [تعليمات المراجعة](prompts/README.md) تمنع الانتقال إلى البرمجة ضمن هذا التكليف.
