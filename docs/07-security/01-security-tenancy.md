# تصميم الصلاحيات والعزل والتهديدات

NSC-SEC-01 | ضوابط مستهدفة غير مختبرة | 2026-11-09.

## نموذج التفويض

القرار = هوية فعالة + عضوية مؤسسة + صلاحية فعل + نطاق مكتب/مجموعة + قيد كائن وحالته. الواجهة تخفي الأفعال غير المتاحة لتحسين الاستخدام، لكن الخادم يعيد التحقق في كل مرة. صلاحية قائمة لا تعني صلاحية مرفق أو تقرير مشتق.

- المستفيد: إنشاء طلب وقراءة طلباته وإضافة رد عام؛ مشاركة طلب مع شخص آخر تحتاج تفويضًا صريحًا.
- الفني: قراءة ومعالجة نطاق مجموعاته، وملاحظات داخلية مسموحة؛ لا يغير سياسة SLA أو منح الأدوار.
- قائد الدعم: إعادة تعيين وتصعيد وتقارير فريقه؛ لا يعتمد شراء لمجرد كونه قائدًا.
- الموافق: قراءة الحد الأدنى اللازم للمورد المكلف بمراجعته وإضافة قرار ضمن نسخة صحيحة؛ لا يحرر طلب الموافقة.
- مدير الأصل/المخزن: حركات وحجز واستلام ضمن اختصاصه؛ ربط أصل بتذكرة لا يمنحه نصها تلقائيًا.
- مدير المؤسسة: إدارة إعداداتها وأدوارها؛ الوصول لمكاتب سرية يحتاج منحًا مستقلًا مدققًا.
- المدقق: قراءة أدلة وتصدير محدود ومراقب؛ لا تعديل ولا إلغاء.
- مسؤول المنصة: إدارة الحالة التشغيلية؛ الوصول الاستثنائي لمؤسسة يحتاج سببًا واعتمادًا وحدًا زمنيًا وسجلًا.

## العزل

المقترح tenant_id مع تفويض تطبيقي وRLS دفاع إضافي في PostgreSQL. هوية المؤسسة تأتي من عضوية مصادق عليها؛ لا يُعتمد رأس HTTP أو حقل حمولة دون التحقق. دور التشغيل ليس مالك قاعدة البيانات ولا يملك تجاوز RLS. يضبط السياق لكل معاملة ويزال عند انتهائها لمنع تسربه عبر الاتصالات المعاد استخدامها. فشل السياق يعني المنع.

نفس السياسة تشمل العامل والتصدير والبحث والتخزين المؤقت والمرفقات والاشتراكات اللحظية. مفاتيح cache تحمل المؤسسة ونطاق الصلاحية، وإلغاء الوصول يبطل النتائج الحساسة. روابط الملفات قصيرة الصلاحية تصدر بعد تفويض؛ أسماء الملفات ليست حماية. فهارس البحث تعيد تطبيق تفويض الوثائق.

عزل المؤسسات لا يكفي لحماية موارد HR داخل المؤسسة؛ service_desk_id ونطاق جمهور السجل جزء من التفويض. التقارير الإجمالية لا تكشف حتى أعدادًا حساسة لنطاق غير مرئي.

## تهديدات وتصميم معالجتها

- تبديل معرف كائن: تفويض على المورد والروابط والمرفقات، واختبارات AC-01 وAC-06 وAC-22.
- تزوير موافقة: هوية موثقة، تحقق النسخة والتفويض ومنع إعادة الاستخدام، AC-09.
- حقن محتوى في تعليق أو مرفق: تطبيع إدخال وعرض آمن وفحص ملفات وعزل قبل النشر، دون تشغيل محتوى نشط.
- SSRF عبر Webhook: وجهات مسموحة، تحقق عنوان الوجهة الفعلي والتحويلات، وفصل شبكة الموصلات.
- أسرار موصل مسربة: مخزن أسرار، عدم إظهار القيمة بعد حفظها، تدوير وتفويض منفصل وقيود خروج.
- حقن تعليمات AI أو كشف عبر البحث: نصوص غير موثوقة، وصول بحسب المصدر، مراجعة بشرية، واختبار AC-20.
- تصدير ضخم أو استعلام مرهق: حدود استخدام، صلاحية تصدير، رابط محدود، وتدقيق العملية.

## الاحتفاظ والتدقيق

تسجيل الحدث لا يثبت وحده عدم قابليته للتلاعب. يمنع حساب التطبيق تعديل سجلات التدقيق، وتقترح نسخة مستقلة ذات صلاحية كتابة محدودة؛ إثبات المقاومة للتغيير يحتاج تحققًا منفصلًا. مدد الاحتفاظ للطلبات والمرفقات والتدقيق والنسخ الاحتياطية غير محسومة وتُعتمد حسب المؤسسة.

تصنيف مبدئي: عام للمقالات المنشورة للعامة فقط؛ داخلي للإجراءات؛ مقيد لبيانات الموظفين والعقود؛ سري للاعتمادات. كلمات المرور ومفاتيح الوصول لا تدخل طلبًا أو تقريرًا أو prompt. لا توجد شهادة امتثال أو نتيجة فحص أمنية ضمن هذه الوثائق.
