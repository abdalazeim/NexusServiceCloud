## 1. ملخص تنفيذي

تحدد هذه الوثيقة خريطة الشاشات وتجربة الاستخدام لمنصة NexusServiceCloud. تعتمد الواجهة على **Next.js 16 + React 19 + BFF** (Backend for Frontend) مع تصميم متجاوب يدعم سطح المكتب والهاتف عبر PWA. التوثيق تصفري ولم يُنفذ أي واجهة بعد.

---

## 2. المبادئ التوجيهية للتصميم

| المبدأ | الوصف |
|--------|--------|
| **مكاتب الخدمة كمركز واحد** | نقطة اتصال واحدة لجميع الطلبات عبر الأقسام (ESM) |
| **دور-based UI** | الشاشات تُعرض بناءً على دور المستخدم ونطاق تفويضه فقط |
| **الاستجابة الفورية** | إجراءات الانتقال والتعيين تُظهر حالة التحميل والنتيجة فورًا |
| **العزل المرئي** | لا تُعرض بيانات مؤسسة أخرى أو نطاق غير مصرح به |
| **الوصولية (Accessibility)** | تباين ألوان، دعم قارئ الشاشة، تنقل بلوحة المفاتيح |
| **العربية أولًا** | واجهة كاملة باللغة العربية مع دعم RTL |

## 4. تدفقات المستخدم الرئيسية (User Flows)

1. **تقديم طلب خدمة**: المستفيد يدخل البوابة → يختار خدمة → يختار عنصرًا من الكتالوج → يملأ النموذج → يرفع مرفقات → يرسل → يُنشأ طلب برقم وحالة SLA.
2. **معالجة طلب**: الفني يرى الطلب في صندوق الوارد → يقرئ التفاصيل → يضيف تعليق داخلي → يسجل عملًا → ينقل الحالة إلى "قيد المعالجة" → يحل ويغلق.
3. **تصعيد طلب**: قائد الدعم يرى الطلب المتجاوز لـ SLA في لوحة التصعيد → يعيد تعيينه لفني آخر أو مجموعة أعلى → يسجل سبب التصعيد.
4. **موافقة**: الموافق يرى طلب موافقة في صندوق وارد الموافقات → يقرئ المرفقات → يضيف قرار (موافقة/رفض) مع سبب → يُسجل القرار.

## 5. تصميم الهاتف (Mobile)

- شاشات مهيأة للمس (touch-first) مع أزرار كبيرة ومسافات كافية.
- التنقل عبر شريط سفلي (bottom navigation) للشاشات الرئيسية.
- سحب للتدليل (pull-to-refresh) لتحديث الطلبات.
- إشعارات دفع تظهر على شاشة القفل للطلبات العاجلة.
- مسودات تُحفظ محليًا وتُرسَل عند استعادة الاتصال.

| المكون | الوصف | الحالة |
|--------|--------|--------|
| زر إجراء أساسي | زر بحشو وألوان افتراضية للمنصة | مخطط |
| بطاقة طلب | عرض ملخص الطلب مع حالة ولون أولوية | مخطط |
| جدول الطلبات | جدول مع فرز وفلتر وترقيم صفحات | مخطط |
| نموذج ديناميكي | نموذج يُولد من تعريف عنصر الكتالوج | مخطط |
| شارة الحالة | شارة ملونة حسب حالة الطلب (مفتوح، قيد المعالجة، مغلق) | مخطط |
| شريط الإشعارات | شريط أعلى يعرض الإشعارات غير المقروءة | مخطط |
