## 4. القاموس (Glossary)

| المصطلح | التعريف |
|--------|---------|
| **ITSM** | إدارة خدمات تقنية المعلومات (IT Service Management) |
| **ESM** | إدارة خدمات المؤسسات (Enterprise Service Management) — امتداد مكاتب الخدمة لأقسام غير تقنية |
| **SLA** | اتفاقية مستوى الخدمة (Service Level Agreement) |
| **OLA** | اتفاقية مستوى التشغيل (Operational Level Agreement) — بين فرق داخلية |
| **incident** | حادث — انقطاع أو تدهور غير مخطط للخدمة |
| **service request** | طلب خدمة — احتياج معتاد ومخطط |
| **problem** | مشكلة — سبب غير معروف لواحد أو أكثر من الحوادث |
| **change** | تغيير — إضافة أو تعديل أو إزالة أي شيء قد يؤثر على الخدمات |
| **CI** | عنصر التكوين (Configuration Item) — أصل تحت السيطرة في CMDB |
| **CMDB** | قاعدة بيانات عناصر التكوين (Configuration Management Database) |
| **tenant** | مستأجر — مؤسسة معزولة بياناتها عن المؤسسات الأخرى |
| **RLS** | أمان على مستوى الصف (Row Level Security) — عزل بيانات في قاعدة البيانات |
| **RBAC** | التحكم في الوصول بناءً على الدور (Role-Based Access Control) |
| **ABAC** | التحكم في الوصول بناءً على الصفة (Attribute-Based Access Control) |
| **JIT** | الوصول في الوقت المناسب (Just-In-Time Access) — صلاحيات مؤقتة |
| **BFF** | Backend for Frontend — طبقة تجميع بيانات للواجهة الأمامية |
| **PWA** | تطبيق ويب متقدم (Progressive Web App) |
| **Outbox** | نمط events الموثوق — كتابة الأحداث في جدول ضمن المعاملة نفسها |
| **Idempotency** | عدم القابلية للتكرار — نفس العملية تنتج نفس النتيجة عند الإعادة |
| **correlation_id** | معرف ارتباط لربط طلبات أنظمية متعددة في تتبع واحد |
| **quarantine** | حجر صحي — حالة مرفق لم يُفحص بعد ولا يمكن تنزيله |
