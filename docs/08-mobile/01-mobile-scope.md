# نطاق الهاتف وتجربة الاتصال

NSC-MOB-01 | مؤجل إلى P4 | 2026-11-09.

واجهة الويب المتجاوبة هي القناة الأولية. عميل الهاتف المقترح يعرض قائمة الطلبات وتفاصيلها وردودها وتعييناتها، ويلتقط مرفقًا ويرسل إشعارًا مختصرًا. تطبيق Android أو iOS أو تقنية مشتركة قرار غير محسوم، ولا يُنقل اختيار Kotlin/Swift من المرجع تلقائيًا.

دون اتصال يسمح بمسودة محلية فقط في خط الأساس؛ يظهر أنها غير مرسلة، ولا يولد رقم طلب نهائي أو SLA. عند العودة يعاد تحقق الجلسة وحقول النموذج ونسخته. تستخدم عملية الإرسال معرفًا ثابتًا لمنع تكرار التذكرة إذا انقطع الإقرار.

الموافقة والإغلاق والتعيين وقراءة الأصول الحساسة تتطلب اتصالًا وحالة خادم حديثة. عند اختلاف نسخة الطلب تعرض مقارنة وإعادة تحميل؛ لا تُدمج حالتان متعارضتان تلقائيًا.

التخزين المحلي مقيد بالحساب والمؤسسة ومشفّر وفق إمكانات المنصة المختارة. تسجيل الخروج يبطل الرموز ويزيل الذاكرة المؤقتة، والمسودات تعالج وفق سياسة معلنة بدل نقلها للحساب الجديد. إشعار شاشة القفل لا يحتوي نص تذكرة حساسة؛ فتحه يعيد التفويض وقد يظهر «لم يعد الوصول متاحًا».

سيناريو القبول AC-24 يشمل رفع مرفق متقطع، تبديل المؤسسة، إيقاف العضوية، واستعادة الاتصال. لا توجد حاليًا ملفات تطبيق هاتف أو APK أو بناء موثق.
