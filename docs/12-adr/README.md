# سجل القرارات المعمارية

NSC-ADR-INDEX | جميع القرارات التالية مقترحة وغير معتمدة | 2026-11-09.

## ADR-001 — وحدات ضمن تطبيق موحد

السياق: مجال كبير مع معاملات تربط الطلب والتدقيق والموافقة. المقترح Modular Monolith بحدود مجال واضحة. البدائل: خدمات مستقلة منذ البداية، أو تطبيق غير مقسم. السبب: تقليل الاتصالات الموزعة مع الحفاظ على الملكية. الأثر: نشر الخلفية كوحدة في البداية مع فصل العمال عند الحاجة. إعادة النظر عند قياس حاجة توسع مستقلة أو اختلاف دورة نشر جوهري.

## ADR-002 — العزل في التطبيق والتخزين

السياق: مؤسسات مستقلة ومكاتب سرية داخل المؤسسة. المقترح tenant_id وRLS مع تفويض المورد والمكتب. البدائل: قاعدة لكل مؤسسة أو schema لكل مؤسسة. الأثر: ضرورة اختبار سياق المعاملة والعامل والبحث، وفصل حساب التشغيل عن الترحيل. إعادة النظر إذا فرض عقد عميل عزلًا ماديًا أو إقامة بيانات مختلفة. RLS وحده لا يحل خصوصية المكتب.

## ADR-003 — نسخ السياسات والقوالب

السياق: تغيّر SLA والنموذج والموافقة أثناء معالجة طلب قد يحرف التاريخ. المقترح تثبيت نسخها عند بدء العملية مع أمر صريح لإعادة الإسناد. البديل قراءة آخر إعداد عند كل عملية. الأثر: بيانات تاريخية أكثر وتقارير أدق؛ تحتاج واجهة مقارنة الأثر قبل النشر.

## ADR-004 — أحداث موثوقة قابلة للتكرار

السياق: لا يجب أن يؤدي انقطاع البريد إلى فقد التذكرة. المقترح Outbox داخل المعاملة وInbox للمستهلك وسجل محاولات. البديل اتصال خارجي داخل المعاملة أو نشر غير موثوق بعدها. الأثر: اتساق لاحق وحاجة رصد وتنظيف مدروس؛ لا وعد exactly-once عبر الأنظمة الخارجية.

## ADR-005 — API موحد وقنوات متعددة

السياق: ويب وهاتف وموصلات. المقترح عقد واحد لتطبيق قواعد العمل مع BFF اختياري للويب. البديل منطق مختلف لكل عميل. الأثر: تفويض مركزي وتوافق نسخ؛ العقد المفاهيمي الحالي يحتاج OpenAPI تفصيلي لاحقًا، ولا يدعي أنه موجود.

## ADR-006 — AI مساعد قابل للفصل

السياق: اقتراحات غير حتمية وبيانات مؤسسات حساسة. المقترح إيقافه افتراضيًا حتى اعتماد المورد والبيانات والكلفة، وحصره في اقتراحات يراجعها الإنسان. البديل أفعال مستقلة آلية. الأثر: عمل أساسي مستقل عن المزود، وكلفة مراجعة بشرية. إعادة النظر تتطلب تحليل خطر وتفويض فعل محدد وليس تفويضًا عامًا للنموذج.

## طريقة الاعتماد

يسجل لكل قرار مالك فعلي وتاريخ وسبب وأثر في FR/NFR وخطة التحقق. الحالات: مقترح، معتمد، مرفوض، مستبدل بقرار آخر. لم يُسجل اعتماد فعلي في هذا التسليم.
